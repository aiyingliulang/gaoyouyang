# 稿有样 Draftory

## 打开方式
双击根目录的 `index.html`，使用最新版 Chrome 或 Edge 打开。首次及每次打开时需要联网加载 Markdown 解析库；应用不依赖后端。浏览器需允许剪贴板写入；若复制失败，请检查权限或更换浏览器。草稿保存在当前浏览器的 localStorage 中，不同浏览器或清除站点数据后可能无法恢复。

## 功能
- Markdown 实时编辑、预览与草稿自动保存。
- 默认、简约、文艺三套公众号主题；复制出的 HTML 将排版样式写在元素的 `style` 属性中。
- 一键复制 HTML 富文本，可粘贴到公众号编辑器。最终呈现可能因公众号编辑器处理方式而有所差异。
- 违规词自查：高亮编辑区中的命中内容，显示总次数与每个词的次数；自查后修改内容会自动更新结果。词库检查仅按字面匹配，不能替代人工审核。
- 按渲染后的正文文本统计非空白字符，阅读时长按每分钟 400 字向上取整。
- 小红书图文卡片入口指向 `cards/cards.html`，可从入口访问。

## CDN
- marked 12.0.2：`https://cdn.jsdelivr.net/npm/marked@12.0.2/marked.min.js`。CDN 不可用时无法生成预览和富文本，但编辑和本地保存仍可使用。

## 维护词库
打开 `app.js`，修改文件顶部的 `forbiddenWords` 字符串数组，按现有格式添加或删除词条，保存后刷新页面即可。重复词条会自动去重；每个词按非重叠出现次数计数。

## 稿有样 Pro 激活与使用

点击页眉的「稿有样 Pro」或自查按钮旁带锁的「高级自查」，在对话框中输入激活码并点击「激活」。输入会自动去除首尾空格并转换为大写；激活状态保存在当前浏览器的 localStorage 中。页面加载不会自动弹出对话框。

激活后可开启高级自查，在基础词库之外检查扩展词库与自定义词库，结果标注来源。自定义词库在自查区上方编辑，**每行一个词**，输入后自动保存在当前浏览器；只有开启高级自查时参与检查。取消激活可点击自定义词库旁的「取消激活」，或点击页眉的 Pro 状态后取消；取消后自定义词仍保存在浏览器中，重新激活后可继续使用。

20 个激活码明文存放在项目根目录的 `ACTIVATION-CODES-PRIVATE.txt`。这是内部保管文件，禁止随部署包分发、禁止提交到任何仓库。页面仅包含激活码的 SHA-256 哈希。本地校验与 localStorage 状态可被有意修改，不能作为可靠的服务端授权或防复制机制。

维护扩展词库可修改 `app.js` 顶部的 `proWords` 数组。若同一词出现在多个词库，优先按基础、扩展、自定义的顺序标注一次。
